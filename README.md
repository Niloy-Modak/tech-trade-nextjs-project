# 🛒 Tech Trade

Tech Trade is a web application where users can manage products with full **CRUD operations** (Create, Read, Update, Delete) and add items to their **shopping cart**.

---

## 🚀 Features
- Add, update, delete, and view products 
- Add products to cart  
- Remove single or all items from cart  
- Responsive design with a smooth user experience
